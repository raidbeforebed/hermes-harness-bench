# Provenance

## Failure taxonomy

The failure classes each task targets come from:

> Harness-Bench: Measuring Harness Effects across Models in Realistic Agent Workflows
> Yilun Yao et al., Peking University, arXiv:2605.27922, May 2026.

Rates cited in the task table are that paper's Table 3. The 22.6 turn and 139.7K
token figures for the Hermes harness are its Table 2.

## Task provenance

Tasks 07, 08, 09 and 10 are adapted from category descriptions in the roadmap
section (15) of Bent-Solutions/hermes-bench, which is MIT licensed. That project
lists them as future work; the task content and graders here are original.
No code from that project is included.

Tasks 01 to 06, 11 and 12 are original to this repository.

## Privacy

Published result records contain only scores, check names, turn counts, token
counts, wall time and exit codes. Model transcripts, file paths and environment
output were deliberately excluded.
